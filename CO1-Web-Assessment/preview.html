Web Development Standards Implementation

Internet Programming (CO-1)

Develop well-structured, standards-compliant web pages using HTML/XHTML and XML and apply Internet protocols and HTTP communication mechanisms.

Video HTTP Navigation XML Protocol

Scenario

A startup is developing a modern web application. During development, the team encounters issues related to HTML elements, HTTP methods, semantic HTML, XML syntax, and communication protocols. The following analysis provides the correct implementation according to web standards.

Question 1 : Video Embedding

Option Code Status
A <media src="video.mp4"></media> Invalid
B <video src="video.mp4" controls></video> Correct
C <movie> Invalid
D <vid> Invalid

Answer

  • The correct HTML element is <video>.
  • It is an HTML5 standard element for embedding videos.
  • The controls attribute provides Play, Pause, Volume, and Fullscreen controls.
  • Other tags are not valid HTML elements.

Question 2 : Registration Form Submission

Method Purpose
GET Retrieve data
POST Create or submit data securely
PUT Update existing resource
DELETE Delete resource

Answer

  • POST sends data inside the request body.
  • User information is not visible in the URL.
  • POST supports large amounts of data.
  • Registration forms should always use POST with HTTPS.

Question 3 : Semantic Navigation

Option Status
<div> Generic Container
<nav> Correct Navigation Element
<section> Content Section
<header> Header Area

Answer

  • <nav> represents navigation links.
  • Improves accessibility for screen readers.
  • Helps search engines understand page structure.
  • Follows semantic HTML5 standards.

Question 4 : XML Syntax

Option Status
A Root element not closed
B Valid XML
C Mismatched tags
D Closing tag incomplete

Correct XML

<note>
    <to>User</to>
    <from>Admin</from>
</note>

Explanation

  • Every XML tag must have a matching closing tag.
  • Tags must be properly nested.
  • XML is case-sensitive.
  • All opening tags require corresponding closing tags.

Question 5 : Web Communication Protocol

Protocol Purpose
FTP File Transfer
HTTP / HTTPS Web Communication
SMTP Email Transfer
SNMP Network Management

Answer

  • HTTP is the standard protocol for communication between web browsers and servers.
  • HTTPS encrypts data using TLS/SSL.
  • FTP transfers files only.
  • SMTP is used for email.
  • SNMP monitors network devices.

Conclusion

Modern web applications should use HTML5 semantic elements, POST with HTTPS for secure forms, valid XML syntax, and HTTP/HTTPS for browser-server communication. Following web standards improves security, accessibility, maintainability, and compatibility across browsers.
