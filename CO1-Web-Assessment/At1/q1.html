Question 1

HTTP Response Analysis

Home

HTTP Header

HTTP/1.1 200 OK
Date: Mon, 01 Apr 2026 10:00:00 GMT
Content-Type: text/html
Content-Length: -150
Connection: keep-alive

Answer

  • Content-Length is invalid because it cannot be negative.
  • A negative Content-Length causes browsers to misread response size.
  • Status code 200 OK does not fully match because the response header is malformed.
  • Correct Content-Length should be a positive value such as 150.
